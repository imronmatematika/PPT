TURUNAN PERTAMA
FUNGSI ALJABAR

f(x) = xⁿ → f'(x) = nxⁿ⁻¹

Materi Pembelajaran Matematika

Belajar Memahami Konsep Turunan

Tujuan Pembelajaran

Setelah mempelajari materi ini, peserta didik diharapkan mampu:

  • Memahami pengertian turunan pertama fungsi aljabar.
  • Mengetahui rumus dasar turunan.
  • Menentukan turunan pertama suatu fungsi.
  • Menyelesaikan soal turunan fungsi aljabar.
  • Menerapkan konsep turunan dalam kehidupan sehari-hari.

Pengertian Turunan

Turunan merupakan konsep matematika yang digunakan untuk mengetahui tingkat perubahan suatu fungsi terhadap variabelnya.

Turunan pertama menunjukkan laju perubahan sesaat suatu fungsi.

f'(x) = lim h→0 [f(x+h)-f(x)] / h

Turunan juga dapat diartikan sebagai gradien garis singgung pada suatu kurva.

Rumus Dasar Turunan

Jika f(x) = c, maka f'(x) = 0
Jika f(x) = xⁿ, maka f'(x) = nxⁿ⁻¹
Jika f(x) = a xⁿ, maka f'(x) = an xⁿ⁻¹
Jika f(x) = u(x) ± v(x), maka f'(x) = u'(x) ± v'(x)

Aturan Pangkat

Aturan pangkat merupakan aturan utama dalam menentukan turunan fungsi aljabar.

f(x) = xⁿ

f'(x) = n · xⁿ⁻¹

Langkah-langkah:

  • Turunkan pangkat menjadi koefisien.
  • Kurangi pangkat dengan satu.
  • Sederhanakan hasilnya.

Contoh Soal 1

Tentukan turunan pertama dari:

f(x) = 3x² + 5x - 7

Penyelesaian:

f'(x) = 3(2)x²⁻¹ + 5(1)x⁰ - 0

f'(x) = 6x + 5

Jawaban: f'(x) = 6x + 5

Contoh Soal 2

Tentukan turunan pertama fungsi berikut:

f(x) = 4x³ - 2x² + 6x - 8

Penyelesaian:

f'(x) = 12x² - 4x + 6 - 0

f'(x) = 12x² - 4x + 6

Jawaban: f'(x) = 12x² - 4x + 6

Penerapan Turunan

Turunan memiliki banyak manfaat dalam kehidupan sehari-hari, antara lain:

📈 Ekonomi: Menghitung biaya marginal dan keuntungan marginal.

🚗 Fisika: Menghitung kecepatan dan percepatan sesaat.

📊 Optimasi: Menentukan nilai maksimum dan minimum suatu fungsi.

Latihan Soal

Tentukan turunan pertama dari fungsi berikut:

1. f(x) = 5x² + 3x - 4

2. f(x) = 2x³ - 6x² + 4x

3. f(x) = 7x⁴ - 3x² + 9

Kerjakan secara mandiri!

Kesimpulan

Turunan pertama fungsi aljabar merupakan konsep untuk menentukan laju perubahan suatu fungsi.

f(x) = xⁿ

f'(x) = nxⁿ⁻¹

Hal penting yang harus diingat:

  • Konstanta memiliki turunan nol.
  • Pangkat dikalikan ke koefisien.
  • Pangkat dikurangi satu.
  • Setiap suku diturunkan secara terpisah.
